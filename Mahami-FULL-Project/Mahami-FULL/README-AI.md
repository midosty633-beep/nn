# مهامي — تشغيل بدون تسجيل دخول

## طريقة البدء
عند فتح التطبيق تظهر شاشة واحدة فقط: **اكتب اسمك** ثم اضغط **ابدأ رحلتك**. لا توجد شاشة Google أو Apple أو بريد إلكتروني أو زر ضيف.

يحفظ التطبيق اسمك محليًا، وينشئ في الخلفية جلسة مستخدم مجهولة وموقعة للسيرفر حتى تعمل خدمات Claude وتذاكر الدعم والتصنيف دون طلب بيانات دخول.

## تشغيل السيرفر
```bash
npm install
npm start
```

الملف `index.html` يستخدم افتراضيًا `http://localhost:3000`. عند النشر على GitHub Pages ضع `window.MAHAMI_API_BASE_URL` قبل كود التطبيق ليشير إلى سيرفر مهامي.

## المفتاح السري
ضع `ANTHROPIC_API_KEY` و`SESSION_SECRET` في `.env` على السيرفر فقط. لا تضع المفتاح داخل `index.html`.

## ملاحظة
تم إزالة واجهة تسجيل الدخول بالكامل من التطبيق. مسارات OAuth والبريد القديمة في السيرفر غير مستخدمة من الواجهة الحالية، بينما المسار المجهول `/api/auth/anonymous` هو المستخدم تلقائيًا بعد كتابة الاسم.
